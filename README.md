## Primeros pasos

1. Leé `Program.cs` antes de ejecutarlo para identificar origen, destino y tablas involucradas.
2. Configurá únicamente bases locales de práctica y prepará las tablas de destino.
3. Abrí `SqlBulkCopy CSharp.sln` y ejecutá el ejemplo en ese entorno controlado; la operación copia datos y no es una consulta de solo lectura.

## Entorno de aprendizaje

Este repositorio conserva ejercicios y versiones de su etapa de estudio. Revisá los archivos de proyecto para preparar el SDK, runtime o servidor correspondiente; esta actualización del README no migra dependencias ni acredita una ejecución reciente de todos los ejemplos.
